# ✈️ Highcloud Airlines Data Analysis Project

## 📊 Project Overview

The **Highcloud Airlines Data Analysis Project** is a data analytics project focused on analyzing airline booking data to identify important business insights, customer behavior, booking patterns, cancellations, and overall performance.

The project uses **Power BI** to transform raw airline booking data into an interactive dashboard that helps users understand key performance indicators and make data-driven decisions.

## 🎯 Objectives

* Analyze airline booking and customer data.
* Identify booking and cancellation trends.
* Measure key business KPIs.
* Understand customer booking behavior.
* Analyze revenue and booking performance.
* Create interactive and user-friendly Power BI dashboards.
* Provide actionable insights for business decision-making.

## 🛠️ Tools & Technologies

* **Power BI**
* **Microsoft Excel**
* **SQL**
* **DAX**
* **Data Cleaning & Transformation**
* **Data Visualization**

## 📁 Dataset

The project uses airline booking data containing information related to:

* Booking details
* Customer information
* Flight information
* Ticket class
* Booking status
* Cancellation details
* Revenue/fare information
* Passenger details

## 📈 Dashboard Features

The Power BI dashboard includes:

### KPI Cards

* Total Bookings
* Total Passengers
* Total Revenue
* Cancelled Bookings
* Cancellation Rate

### Visualizations

* Booking trends
* Cancellation analysis
* Revenue analysis
* Passenger segmentation
* Ticket/class analysis
* Booking status distribution
* Interactive filters and slicers

## 🔍 Key Insights

The dashboard helps identify:

* Overall booking performance.
* Cancellation patterns.
* Revenue contribution.
* Customer and passenger behavior.
* Differences between booking classes.
* Areas where airline performance can be improved.


## 💡 Business Value

This project demonstrates how data analytics and visualization can help an airline:

* Monitor business performance.
* Understand customer behavior.
* Reduce cancellation impact.
* Identify revenue opportunities.
* Improve operational and business decisions.
